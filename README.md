Python Tip Calculator 🧮

A beginner-friendly Python project that calculates the total bill, including a tip, and splits the amount equally among multiple people.

Features

- Takes the total bill as input
- Accepts the tip percentage
- Calculates the total bill with tip
- Splits the bill among people
- Rounds the final amount to two decimal places

Technologies Used

- Python

Concepts Practiced

- Variables
- User input
- Type conversion
- Arithmetic operators
- F-strings
- "round()" function

How to Run

python task.py
